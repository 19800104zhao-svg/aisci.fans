# Security Policy

AISci.fans is currently a static, client-side site. It does not collect credentials, process payments, or send submitted research signals to a remote service.

## Reporting

If you find a vulnerability, please open a private security advisory in GitHub once the repository is live, or contact the repository owner directly.

## Baseline Controls

- Local-only JavaScript and CSS, with no third-party runtime scripts.
- Content Security Policy for static hosting.
- No network submissions from the signal form in the current version.
- No use of cookies, analytics scripts, or tracking pixels.
